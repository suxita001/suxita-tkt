# suxita_001: ქართული თამაშები

TikTok-ზე აწყობილი ქართული თამაშები, რომლებიც პირდაპირ ბრაუზერში ითამაშება.

საიტი: https://suxita001.github.io/suxita-tkt/

## თამაშები

- **ღიპიანი თამადა** (`games/ghipiani-tamada/`): ღიპიანი თამადა ყანწით დაფრინავს თბილისის თავზე. Python/pygame, ბრაუზერისთვის აწყობილია pygbag-ით.

## ახალი თამაშის დამატება

1. თამაშის ვებ-ვერსია (`index.html` და სხვა ფაილები) ჩადე ახალ საქაღალდეში `games/<სახელი>/`.
2. თამაშის სურათი ჩადე `assets/` საქაღალდეში.
3. `index.html`-ში, „თამაშები“ ბლოკში დაამატე ახალი ბარათი (`<a class="card">`).
